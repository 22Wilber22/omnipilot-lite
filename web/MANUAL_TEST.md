# Verificación manual — proyecto local

Estado: pendiente de ejecutar en navegador con el servidor iniciado, un token local válido y `~/OmniPilotProjects/prueba-omnipilot` disponible.

1. Elegir **Proyecto local**.
2. Escribir `prueba-omnipilot` e inspeccionar.
3. Confirmar que aparecen el nombre, el estado Git y los scripts de `package.json`.
4. Elegir `test` como prueba de aceptación.
5. Enviar una tarea y confirmar que el plan muestra el proyecto, `npm run test` y la nota sobre la copia temporal.
6. Confirmar que el run permanece pendiente y no muestra actividad de ejecución.
7. Pulsar **Aprobar y ejecutar** únicamente cuando se quiera iniciar la corrida.

La plantilla de demostración debe conservar su validación integrada y no requiere inspección.
